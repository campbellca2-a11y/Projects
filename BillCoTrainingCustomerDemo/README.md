# BillCo Training Customer Demo

Customer-facing front door for the BillCo Training concept.

## Purpose

Explain the LearningLadder visually, show the delivery model, and route prospects to the existing fictional Bill County 911 live demo.

## Safety / content boundary

The public BillCo demo is fictional. Do not place Delaware County or another agency's training material into the public customer demo.

## Live demo dependency

This page links to:

https://billco-demo-vercel-ready.vercel.app/

## Deployment

Deploy this folder as a static Vercel project with no framework and no build command.

Suggested project name: billco-training
