# BillCo Training — Pilot Scope v0.1

## What BillCo Training is

A browser-based training system that turns approved source material into structured learning artifacts and practice tools.

The system is organized as a LearningLadder:

Source material -> Orient -> Encode -> Retrieve -> Discriminate -> Hold -> Apply

Not every pilot needs every rung. The first release should solve the smallest useful training problem.

## Standard pilot deliverables

A standard pilot may include:

- one customer-specific training pack built from customer-authorized source material
- one unified browser hub
- selected reference / study resources
- selected quiz or recall modules
- one public or restricted deployment URL
- one material-correction revision cycle
- one customer Training POC support channel

The exact modules are defined in the accepted intake.

## Typical module types

Reference:
- quick guides
- ladders
- contrast sheets
- abbreviation / geography / code references

Practice:
- recognition
- forward recall
- reverse recall
- SOP retrieval
- subtype / near-neighbor discrimination
- short-term memory recall
- scenario application

## Validation model

Customer source material remains authoritative.

BillCo:
1. structures the material,
2. builds training artifacts,
3. exposes unresolved conflicts rather than guessing,
4. submits the pack for customer validation.

Customer Training POC accepts the pack before go-live.

## Access model

Default pilot:
- shared training URL
- no learner account required
- works in current desktop and mobile browsers
- learner-local history where enabled

A central roster, cloud sync, instructor dashboard, or enterprise identity integration is not included unless separately scoped.

## Operational boundary

BillCo Training is not:
- CAD
- dispatch protocol software
- a phone or radio system
- an LMS roster system
- certification
- a substitute for current SOP, authorized academy material, supervision, or agency policy

It is a study and practice layer.

## Public-demo boundary

Public BillCo demonstrations use fictional content.

Customer content stays inside that customer's training pack and is not reused in another public or customer demo unless separately authorized.

## Pilot success check

At the end of a pilot, the Training POC should be able to answer:

- Was the material accurate enough for classroom use?
- Could learners use the site without blocking failures?
- Did the selected LearningLadder artifacts address the target training problem?
- Is the delivery model acceptable for continued use?
- What should be added, removed, or changed for the next version?
